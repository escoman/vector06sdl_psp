Я полностью изучил структуру и содержимое папки psp, которая содержит PSP-порт эмулятора Вектор-06Ц.

Структура папки psp:
Файл/папка	Назначение
Makefile	Сборочный файл PSPSDK: собирает EBOOT.PBP, копирует в boot/
main.cpp	Точка входа: ROM-браузер → инициализация эмулятора → главный цикл
filebrowser.cpp/h	Сканирование и сортировка ROM-файлов (.rom/.bin) из ms0:/PSP/GAME/VECTOR06C/ROMS
boots.c	Генерируется из boot/boots.bin (2048 байт загрузчика) через xxd -i
assets/	Иконки EBOOT (ICON0.PNG, PIC1.PNG)
boot/	Выходная папка для EBOOT.PBP + ROM-файлы загрузчика
src/	Ядро эмулятора (модифицированные копии из основного src/)

Ключевые компоненты порта:
Однопоточная архитектура (как в Android-версии) — без Boost-потоков
Рендеринг через PSP GU — tv.cpp использует pspgu/pspgum, два фреймбуфера 512x272, текстура 576x288 → 480x272, формат ABGR8888
Звук через PSP Audio Library — sound.cpp с callback'ом 44100 Гц стерео 16 бит, кольцевой буфер
Ввод через sceCtrlReadBufferPositive — маппинг кнопок PSP на сканкоды Вектор-06Ц
Ядро эмуляции (i8080, память, таймер 8253, AY-3-8910, FD1793, PixelFiller) — скопировано без изменений
